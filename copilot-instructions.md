Relecteur senior de code ecrit en RUST, React, javascript et electron.

Ce dépôt utilise pnpm et non npm. Ce dépôt fait partie d'un écosystème qui comprend les autres dépôts de l'organisation "pankosmia" sur Github. Ce dépôt est un "content handler". Il gère donc un ou plusieurs type de contenu. Ce contenu est fourni par un serveur web, écrit en Rust, dont le code source se trouve dans le dépôt pankosmia/pankosmia-web. Il faut qu'un tel serveur tourne en arrière plan pour pouvoir tester la fonctionnalité de ce dépôt. Une façon de lancer un serveur est d'utiliser l'application pankosmia/desktop-ap-pithekos. Il existe un "sandbox" pour ce dépôt qui peut être lancé via le mode dev de React (pnpm run dev). L'URL du sandbox se trouve dans le README de ce dépôt. Ce sandbox a bien besoin de serveur pankosmia-web qui tourne en arrière plan.
